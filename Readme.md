# **A Guessing Number game**

`CLI Based game using rust`

### **Library used**
- **std::io** : (*Standard library of Rust that handles input-output pattern*)
- **rand::{RngExt}** : (*Thrid party library from crates, that handle Random Number Generator*)
- **std::cmp::Ordering** : (*Standard Library of Rust that handles Value/variable comparison, where it implements **cmp** modules for implementing values comparison using an enum of **Ordering** which contains 3 possible states {**Less, Greater, Equal**}.*)
